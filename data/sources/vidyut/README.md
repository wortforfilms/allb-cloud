# Vidyut sutrapatha

`sutrapatha.tsv` is copied unchanged from Vidyut by ambuda.org:

- File: `vidyut-prakriya/data/sutrapatha.tsv`
- Repository: https://github.com/ambuda-org/vidyut
- Commit: `8da2f90bee3ce1c07505fa432fc3729e3f7e02ea` (24 June 2026)
- SHA-256: `f2ff798707e8b8ea20dd5cf20a7bbcc4b849f0ab4d726a0a4af890ef87b7e87c`
- Licence: MIT, see `LICENSE-vidyut.md`. Vidyut's data README says the author of ashtadhyayi.com shared these files under the MIT licence.

It has 3,983 sutras, from 1.1.1 to 8.4.68, in SLP1. Other printed editions count between about 3,959 and 3,996.

The same files are used by Guru in the brahmini repository, under `guru/data/panini`. That folder also has the Dhatupatha and the companion sutra texts.

`dhatupatha.tsv` (same commit, MIT; SHA-256 `bb2013ea…ba380`) is the Dhātupāṭha. `hardware/scripts/prakriya_ref.py` uses it to pick the roots for the prakriyā core and to compare them with Vidyut's derivations.
